# ポータル追加依頼: `/tanebako` の一番上に「今読むもの」を出す

- 依頼元: tanebako セッション（オーナー承認済み 2026-11-23）
- 前回の依頼書: `01_運営/2026-11-23_ポータル_TaneBako閲覧ページ依頼書.md`（実装済み）

## 内容
- `/tanebako`（トップ）の一番上に、`/data/tanebako/00_今読むもの.md` の内容を整形して表示する（その下に既存のフォルダ一覧）。
- ナビの「TaneBako」を開いたとき、まずこれが見えること。長い場合は、見出しごとに折りたたみ可（初期は「1. 今すぐ」と「2. 11-30 まで」を開く）。
- `00_今読むもの.md` は既存の許可リストに追加する（ルート直下のファイルは `00_フォルダの見方.md` と `CLAUDE.md` のみ許可されているため）。
- ファイル内のパス表記（`05_公開物/…` など）は、タップで該当ファイルを開けるリンクにできれば望ましい（任意）。リンク化できない場合はそのままでよい。
- 「更新: YYYY-MM-DD」の行を、ページ上部に目立つように出す。
- 書き込み機能は不要（読み取りのみ）。

## 受け入れ確認
1. iPhone 幅で `/tanebako` を開くと、一番上に「今読むもの・やること」が出る。
2. 許可外のファイル（`.git`、`.claude`、`../` など）は引き続き 404。
3. `portal.service` 再起動後も他のページが従来どおり動く。README に追記し、ローカル git に commit。
