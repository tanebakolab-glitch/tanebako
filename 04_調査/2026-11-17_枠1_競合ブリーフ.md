## 2. 競合の型（個別の人物ではなく型で整理）

### 2-1. 型A「収益額を見せる体験談」（N1・N4・N6）
- 約束: 「ゼロからでも月○万円」。証拠: 自己申告の売上。仕組み: 「やったことの一覧」。
- 強み: 数字が見出しで伝わる。N1 は連載（1〜5ヶ月目）で読者を引っ張り、スキ158。
- 弱み: 売上は検証できず、読者は「本当か」を疑える（推測）。再現方法が具体的でないものは広告色が強まる。

### 2-2. 型B「日次の連載型」（N2・N7）
- 約束: 「毎日晒す」。N2 は「DAY 1/30」形式で、フォロワー2,760の発信者による連載。スキは24（無料）。
- 強み: 継続して読む理由ができる。
- 弱み: 連載の1本目単体のスキは伸びにくい（24）。**型の確認が取れたのは1本のみ**で、一般則にはしない。

### 2-3. 型C「やったこと全部公開（日記型）」（N5）
- 冒頭で「1円も稼げてなかった」と開示し、初収益¥880まで。アフィリエイトの開示が冒頭1行目にある（確認）。スキ2。
- 強み: 正直さ、冒頭の開示。弱み: 差別化の軸がなく、読者への示唆が少ない（推測）。

### 2-4. 型D「結果＋有料パート」（N3）
- 500円の有料。スキ6。フォロワー78。「AI副業30日」で他と同じ見出し（確認）。

## 3. ポジショニングマップ（推測）
横軸: 主役は書き手（体験談）← → 主役は仕組み（設計の公開）
縦軸: 収益額を訴求 ← → 収益額を訴求しない（過程と失敗を訴求）

| 象限 | 該当 | 混み具合 |
|---|---|---|
| 体験談×収益訴求 | N1・N4・N5・N6 | 混んでいる（確認できた範囲） |
| 体験談×過程訴求 | N2・N7（連載型） | やや混んでいる |
| 仕組み×収益訴求 | 確認できず | 空き（広告色が強い層はここ） |
| **仕組み×過程・失敗訴求** | **TaneBako の狙い** | **確認できた範囲では該当なし（調査範囲が狭いので断定しない）** |

## 4. ポジショニング文（案）
> AI副業を試す個人・一人事業の運営者にとって、タネバコは、AIが運営し人間が公開と支出を承認する様子を、数字・失敗・止まった場面つきでそのまま記録するメディアである。なぜなら、売上を競わず、承認の分け方・予算・基準値という「設計」を先に公開するから。

- 避けたい言い方: 「月○万円を目指す」系の収益訴求（収益 0 円の時点では事実と合わず、憲章5章の「実際に起きていないことは書かない」にも反する）。

## 5. 空白領域（機会）
1. **設計を公開する**: 4部門の分担、書く側と審査する側の分離、承認フロー、月5万円の計上範囲。確認できた競合の記事には見当たらない（確認した2本の範囲）。
2. **止まった場面を残す**: 例）X の2つ目のアカウント登録が止まった件。N5 型の「正直さ」を、収益ではなく運営の失敗に使う。
3. **基準を先に公開する**: 稼働前に確定した判定基準（継続/休眠）で結果を測る。後から都合の良い数字を選ばない姿勢が差になる。
4. **開示を最初に置く**: AI運営の明示（憲章5章）は、冒頭にアフィリエイト開示を置く N5 の流儀と同じ向き。

## 6. 脅威
- 「AI副業30日」「30日記録」の見出しが多く、検索・タイムラインで埋もれる。
- 収益額を出す競合のほうが、見出しの訴求力は強い（N1 のスキ158）。収益 0 円の初期は不利。
- X はフォロワー・インプレッションの実測が取れず、競合の伸び方を比べられない。
