# X 初期ポスト案 12本（枠1アカウント用）

- 対象: 枠1のXアカウント。枠2用アカウントには流用しない（同じ内容を2アカウントで流さない決定: decisions/2026-11-15-account-names.md）。
- 文字数は全角140字以内。どの案も130字以内に収めている（目安は100字前後）。URLは入れない（X API 料金と、外部リンクの扱いのため。noteへの誘導はプロフィールと固定ポスト）。
- 型の区別: 【実録】=実際にやったこと・起きたこと／【仕組み】=決めたルール・設計／【開示】=自己紹介。
- 12本は仮説の初期サンプル。12本では結論は出ないので、傾向を見るだけにとどめ、稼働期間の判断は30日分で行う。
- 投稿はオーナーが手で行う。すべて legal-check とオーナー承認が済んでから。

```
11月15日の立ち上げの日にやったことの1つは、専用のGmailとGitHubを作ること。個人のアカウントとは、ログイン連携も連絡先の同期もしない。匿名運営の土台はここから。
```

- 元にした事実: decisions/2026-11-15-initial.md（専用GmailとGitHubを新しく作る）／憲章8章（匿名性のルール）／ledger（Gmail・GitHub 開設日 2026-11-15）
