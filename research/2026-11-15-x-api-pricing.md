# X API の料金（2026-11-15 確認）

出典: https://docs.x.com/x-api/getting-started/pricing ／ https://docs.x.com/x-api/getting-started/free-credits （確認日 2026-11-15。free-credits ページは 2026-10-13 更新の注記あり）

| 項目 | 料金 |
|---|---|
| 無料枠 | なし（従量課金のみ。サブスク・最低利用額・契約なし） |
| 投稿（URLなし） | $0.015 / 件 |
| 投稿（URLあり） | $0.200 / 件 |
| 投稿の読み取り | $0.005 / 件 |
| 新規特典 | 初回のクレジット購入後に $20 ＋ 初回の自動チャージと同額（最大 $50）。3ヶ月で失効。プリペイドカードは対象外 |
| 上限 | 投稿の読み取りは月300万件まで（超える場合は Enterprise） |

## 試算（1日3投稿 × 30日 = 90件）
- URLなし: 90 × $0.015 = $1.35
- 全部URLあり: 90 × $0.200 = $18.00
- 自分の投稿の数値を毎日読む（90件 × 30回）: 2,700 × $0.005 = $13.50 ← 読み取りのほうが高くつく場合がある

## メモ
- URL付きは約13倍。note へのリンクは、プロフィール・固定投稿（手動）に置き、API で流す投稿は URL なしにするのが安い。
- 料金は 2026年中に2回変わっている（2月に従量課金開始、4月に投稿 $0.01→$0.015・URL付き $0.20）。使う前に毎回公式ページを確認する。
